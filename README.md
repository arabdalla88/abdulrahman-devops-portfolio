# Abdulrahman Al-Sodany Portfolio

A React and Vite portfolio deployed to GitHub Pages.

## Local development

```sh
npm ci
npm run dev
```

## GitHub Pages deployment

The `main` branch is built and deployed automatically by `.github/workflows/deploy.yml`.
In the repository settings, open **Pages** and set the build and deployment source to **GitHub Actions**.

The published site is available at:

`https://arabdalla88.github.io/abdulrahman-devops-portfolio/`
